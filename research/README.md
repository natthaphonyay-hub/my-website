# หน้าสรุปงานวิจัย (research one-page)

หนึ่งเรื่อง = ไฟล์ข้อมูลหนึ่งไฟล์ในโฟลเดอร์นี้ หน้าเว็บมีแม่แบบเดียวคือ `research.html` เปิดดูด้วย `research.html?id=<ชื่อไฟล์ไม่มี .js>`

- หน้าตา: `assets/research.css` (จอคอม มือถือ และพิมพ์ A4 หน้าเดียว)
- ตัวแสดงผล: `assets/research.js` (ทุกข้อความถูก escape ใส่ HTML ไม่ได้)
- แก้ css หรือ js เมื่อไร ให้เปลี่ยนป้าย `?v=` ใน `research.html` และค่า `VERSION` ใน `research.js` ให้ตรงกัน

## รูปแบบไฟล์ข้อมูล

ไฟล์ต้องขึ้นต้นแบบนี้ และ id ใช้ได้แค่ a-z 0-9 และขีด

```js
window.RESEARCH_PAGES = window.RESEARCH_PAGES || {};
window.RESEARCH_PAGES['<id>'] = { ... };
```

| ช่อง | ใส่อะไร |
|---|---|
| `status` | `'draft'` = ขึ้นแถบเหลืองว่าเป็นฉบับร่าง, `'published'` = ไม่มีแถบ (เปลี่ยนเมื่อผ่านการตรวจแล้วเท่านั้น) |
| `statusNote` | ข้อความบนแถบฉบับร่าง |
| `reviewed` | วันที่ตรวจทานล่าสุด `YYYY-MM-DD` |
| `tag` `herb` `scientific` | ป้ายหมวด ชื่อไทย ชื่อวิทยาศาสตร์ (ตำรับหลายตัวยา เช่น ลูกประคบ เว้นว่าง `''` ได้) |
| `title` | หัวเรื่องแบบคำถาม |
| `summary` | กล่อง "สรุปสั้น" บนสุด หนึ่งคำถามต่อแถว `[{ q, em, a, refs, tone }]` `em` = คำตอบหลักตัวหนา `a` = ส่วนขยาย `tone: 'no'` = หัวแถวสีแดง ใช้ 5 แถว: ช่วยไหม, เชื่อได้แค่ไหน (ใส่ขนาดหลักฐาน), ผลข้างเคียง, ห้ามใช้ และข้อระวังที่สำคัญที่สุดของเรื่องนั้น |
| `findings` | กราฟผล ดูหัวข้อถัดไป |
| `safety` | รายการเต็ม `avoid` และ `caution` (ความถี่ผลข้างเคียงอยู่ในสรุปสั้นแล้ว ไม่ต้องซ้ำ ช่อง `frequency` ใส่ได้ถ้าจำเป็น) (รายการ `{ text }` สั้น ๆ) พร้อม `avoidRefs` `cautionRefs` ที่แสดงครั้งเดียวที่หัวข้อ |
| `more` | เรื่องที่พับเก็บ กดเปิดเอง `[{ title, text, refs }]` หรือ `[{ title, list: [{ text, refs }] }]` เช่น ข้อจำกัดของหลักฐาน คำถามที่คนมักถาม ที่มาของงานวิจัย |
| `disclaimer` | ข้อความท้ายหน้า |
| `references` | `[{ text, url, urlLabel, note }]` ลำดับในรายการ = เลขที่ใช้ใน `refs` แสดงแบบพับเก็บ เปิดเองเมื่อกดเลขยกหรือสั่งพิมพ์ ลิงก์รับเฉพาะ https |
| `credit` | บรรทัดที่ต้องเห็นเสมอ: แปลและเรียบเรียงจากงานไหน สัญญาอนุญาต ผู้เรียบเรียง วันที่ตรวจทาน |

หลักของหน้า (ปรับ 2026-11-05 ให้ตัวหนังสือน้อยและอ่านเอาข้อมูลได้เร็ว): ส่วนที่เห็นทันทีมีแค่ หัวเรื่องแบบคำถาม กล่องสรุปสั้น กราฟ และรายการความปลอดภัย ที่เหลือพับเก็บใน `more` ไม่พูดเรื่องเดียวกันซ้ำสองที่

ช่วงทดลอง (ตั้งแต่ 2026-11-05): `research.html` มี `<meta name="robots" content="noindex">` กัน Google เก็บหน้า และหน้าคลังความรู้ยังไม่ลิงก์มาที่นี่ เปิดได้เฉพาะคนที่มีลิงก์ตรง ลบบรรทัด noindex เมื่อเผยแพร่จริงหน้าแรก

`refs` คือเลขลำดับใน `references` (เริ่มที่ 1) แสดงเป็นตัวเลขยกท้ายข้อความ

## กราฟผล (`findings`)

| ช่อง | ใส่อะไร |
|---|---|
| `heading` `sub` `subRefs` | หัวข้อ คำอธิบายว่ากราฟมาจากการเปรียบเทียบไหน |
| `axis` | `[ต่ำสุด, สูงสุด]` ของแกน |
| `ticks` | ตัวเลขบนแกน (ไม่ใส่ก็ได้ จะใช้ขอบของ `bands`) |
| `axisLabels` | คำใต้แกนซ้ายและขวา |
| `bands` | `[{ from, word }]` เกณฑ์ขนาดผลตามที่งานวิจัยนั้นเขียนไว้ |
| `unclearWord` `harmWord` | คำเมื่อช่วงความเชื่อมั่นคร่อม 0 และเมื่อผลไปทางแย่ลง |
| `consistency` | `[{ from, word }]` เกณฑ์ I² ตามที่งานวิจัยนั้นเขียนไว้ |
| `rows` | `[{ label, est, lo, hi, i2, people }]` (`people` สั้น ๆ เช่น `314 คน`) |
| `howToRead` `notes` | วิธีอ่านกราฟและหมายเหตุ อยู่ในส่วนพับ "อ่านกราฟนี้อย่างไร" พร้อมตัวเลขและช่วงความเชื่อมั่นที่ตัวแสดงผลสร้างให้เองจาก `rows` |

ค่าในกราฟต้องจัดให้ **ค่าบวก = ดีกว่ากลุ่มเปรียบเทียบ** ถ้าต้นฉบับใช้ค่าลบแปลว่าดีขึ้น ให้กลับเครื่องหมายและสลับขอบ: `est = -est เดิม`, `lo = -hi เดิม`, `hi = -lo เดิม` แล้วเขียนหมายเหตุในไฟล์ว่ากลับแล้ว (ตัวอย่าง: SMD -1.13 [-1.37, -0.89] กลายเป็น 1.13 [0.89, 1.37])

กราฟนี้ใช้กับขนาดผลแบบต่อเนื่องที่มีเกณฑ์ชัด (SMD) ถ้าผลเป็นอัตราส่วน (RR, OR) หรือหน่วยจริง (วัน, คะแนน) ให้เขียนเป็นข้อความหรือจำนวนต่อ 100 คนแทน อย่ายัดลงแกนเดียวกัน

## รายการในหน้าคลังความรู้

`research/index.js` เก็บรายชื่อ id ที่จะขึ้นในหัวข้อ "สรุปงานวิจัย" ของ `knowledge.html` เรียงบนลงล่าง `assets/research-list.js` อ่านหัวเรื่อง ป้าย และคำตอบแถวแรกของสรุปสั้นจากไฟล์ข้อมูลของแต่ละหน้า หน้าที่ยังเป็น `draft` จะมีป้าย "ฉบับทดลอง"
