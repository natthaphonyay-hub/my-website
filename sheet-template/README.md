# คู่มือแก้ข้อมูลเว็บด้วย Google Sheets

เว็บจะอ่านข้อมูลจาก Google Sheets ไฟล์เดียว ที่มี 6 แท็บ แก้ในชีตแล้วเว็บจะเปลี่ยนตามเอง (อาจใช้เวลาไม่กี่นาที)

## ตั้งค่าครั้งแรก (ทำครั้งเดียว)

1. สร้าง Google Sheets ใหม่ **แยกจากโฟลเดอร์เอกสารลับ** (เพราะชีตนี้ต้องเปิดให้ทุกคนดูได้)
2. นำเข้าไฟล์ CSV ทั้ง 6 ไฟล์ในโฟลเดอร์นี้ ทีละไฟล์:
   ไฟล์ → นำเข้า → อัปโหลด → เลือกไฟล์ → **"แทรกแผ่นงานใหม่"** → นำเข้าข้อมูล
3. เปลี่ยนชื่อแท็บให้ตรงนี้เป๊ะ ๆ (ตัวพิมพ์เล็ก): `settings` `products` `news` `articles` `history` `herbs`
4. กด **แชร์** → การเข้าถึงทั่วไป → **ทุกคนที่มีลิงก์** → ผู้มีสิทธิ์ **ผู้ดู**
5. คัดลอก ID ของชีต คือข้อความยาว ๆ ในลิงก์ระหว่าง `/d/` กับ `/edit`
   `https://docs.google.com/spreadsheets/d/`**`1AbC...xyz`**`/edit`
6. นำ ID ไปใส่ในไฟล์ `assets/data.js` บรรทัด `const SHEET_ID = '';` (หรือส่ง ID ให้ผู้ดูแลเว็บใส่ให้)
7. ให้สิทธิ์ **ผู้แก้ไข** เฉพาะพนักงานที่ดูแลเว็บ

## แต่ละแท็บ

**ห้ามเปลี่ยนชื่อหัวคอลัมน์แถวแรก** แก้ได้ตั้งแต่แถวที่ 2 ลงไป เพิ่มแถวใหม่ได้เรื่อย ๆ

### settings — ข้อมูลติดต่อ
แก้ในคอลัมน์ `value` เท่านั้น (key `website` = ลิงก์เว็บไซต์ท้ายเว็บ ใส่ `-` เพื่อซ่อน) เช่น เบอร์โทร, LINE, ลิงก์ LINE, ลิงก์ Google Drive ของเจ้าหน้าที่

### ผลิตภัณฑ์ — ใช้ชีตแยก "รายการยาสมุนไพร (เว็บ)"
หน้าผลิตภัณฑ์อ่านจากชีตแยก (แท็บ `ยา` และ `ปก`) ไม่ใช้แท็บ `products` ในไฟล์นี้แล้ว
| คอลัมน์ | ความหมาย |
|---|---|
| show | `TRUE` = แสดง, `FALSE` = ซ่อน |
| status | `ผลิตปกติ` / `Pre-Order 60 วัน` / `Pre-Order 1 ปี` (ขึ้นเป็นป้ายสีและปุ่มกรอง) |
| unit | `โรงพยาบาล` / `ศูนย์แพทย์แผนไทยพนา` / `ร้านค้ามูลนิธิ` (ปุ่มกรอง ค่าเริ่มต้น = โรงพยาบาล) |
| featured | `TRUE` = ขึ้นแบนเนอร์ผลิตภัณฑ์แนะนำ (มีหลายรายการจะเลื่อนเป็นสไลด์) และการ์ดหน้าแรก |
| image | **ลิงก์แชร์รูปจาก Google Drive** (ดูหัวข้อรูปภาพ) ห้ามแทรกรูปลงในเซลล์ เพราะเว็บอ่านไม่ได้ |
| คอลัมน์อื่น ๆ | แสดงในตาราง และหน้าต่างรายละเอียดเมื่อกดที่รายการ ช่องที่ใส่ `-` หรือเว้นว่างจะไม่แสดง |

**ห้ามเปลี่ยนชื่อหัวคอลัมน์** (สลับลำดับคอลัมน์ได้) · แท็บ `ปก`: แถว `ปีงบประมาณ` และ `อัปเดตล่าสุดวันที่` ขึ้นที่หัวหน้าเว็บและใบ A4

### news — ข่าวสาร
| คอลัมน์ | ความหมาย |
|---|---|
| show | เหมือนด้านบน |
| slide | `ใช่` = ขึ้นในสไลด์ข่าวเด่นหน้าแรก |
| date / tag | วันที่ / ป้ายหมวด เช่น ประกาศ |
| title / summary | หัวข้อ / สรุปสั้น ๆ |
| body | เนื้อหาเต็ม ขึ้นย่อหน้าใหม่ด้วย **Ctrl + Enter** (Mac: Cmd + Enter) ในช่องเดียวกัน |
| image1 / image2 / image3 | ลิงก์รูป ใส่ได้ 1 ถึง 3 รูป (ดูหัวข้อรูปภาพ) |

ข่าวจะเรียงตามลำดับแถว **ข่าวใหม่ให้แทรกไว้แถวบนสุด** (ใต้หัวคอลัมน์)

### articles — คลังความรู้
เหมือนข่าว แต่ใช้ `read` = เวลาอ่าน (นาที) แทนวันที่

### history — เส้นทางของเรา (หน้าเกี่ยวกับเรา)
| คอลัมน์ | ความหมาย |
|---|---|
| show | เหมือนด้านบน |
| year | ปี พ.ศ. |
| text | เหตุการณ์ |
| image1 / image2 / image3 | ลิงก์รูป ใส่ได้ 1 ถึง 3 รูป (ไม่ใส่ก็ได้) |

เรียงตามลำดับแถว เหตุการณ์ใหม่ให้เพิ่มไว้**แถวล่างสุด**

### herbs — ราคารับซื้อสมุนไพร (หน้ารับซื้อสมุนไพร)
| คอลัมน์ | ความหมาย |
|---|---|
| show | เหมือนด้านบน |
| code | รหัสสมุนไพร |
| name | ชื่อ เช่น ไพล สด |
| unit | หน่วย เช่น kg |
| price | ราคาเกรด A (ราคาใหม่) |
| status | `เปิดรับ` หรือ `ปิดรับชั่วคราว` |

ใส่แค่ราคาเกรด A ก็พอ เว็บจะคำนวณเกรด B, C และราคา GAP / อินทรีย์ให้เอง ตามค่าในแท็บ `settings`
(`gradeB` `gradeC` `gapBonus` `organicBonus`) ปัดลงทีละ 0.5 บาทเหมือนตารางเดิม
อย่าลืมแก้ `herbsUpdated` ในแท็บ settings ทุกครั้งที่ปรับราคา

### ปริมาณ — ปริมาณที่ยังต้องการรับซื้อ (หน้ารับซื้อสมุนไพร)
อยู่ใน**ชีตราคารับซื้อสมุนไพร** (ไฟล์เดียวกับแท็บ `ราคา`) เพิ่มแท็บใหม่ชื่อ `ปริมาณ` นำเข้าจาก `herb-wants.csv`
| คอลัมน์ | ความหมาย |
|---|---|
| รายการ | ชื่อสมุนไพร |
| unit | หน่วย เช่น กิโลกรัม |
| ปริมาณที่ยังต้องการ | ตัวเลขโดยประมาณที่ยังต้องการรับเพิ่มในปีงบนี้ ใส่ `0` = ขึ้นว่า "ครบแล้ว" ใส่ข้อความก็ได้ เช่น `ไม่จำกัด` |
| หมายเหตุ | เว้นว่างได้ |
| show | `TRUE` = แสดง, `FALSE` = ซ่อน |

- วันที่อัปเดต: เพิ่มแถวในแท็บ `ปก` โดย key = `ปริมาณอัปเดตวันที่` และ value = วันที่ เช่น `1 ตุลาคม 2569`
- ถ้ายังไม่มีแท็บ `ปริมาณ` หรือไม่มีแถวที่แสดง หัวข้อนี้จะไม่ขึ้นบนเว็บ

## รูปภาพ
1. อัปโหลดรูปลง Google Drive (โฟลเดอร์รูปสำหรับเว็บ **แยกจากเอกสารลับ**)
2. คลิกขวาที่รูป → แชร์ → **ทุกคนที่มีลิงก์** → คัดลอกลิงก์
3. วางลิงก์ในคอลัมน์ `image` ได้เลย เว็บจะแปลงให้เอง

### ข่าว คลังความรู้ และเส้นทางของเรา: ใส่ได้ 1 ถึง 3 รูป
ใช้คอลัมน์ `image1` `image2` `image3` (ชีตเดิมที่มีคอลัมน์ `image` คอลัมน์เดียวยังใช้ได้ เว็บจะนับเป็นรูปที่ 1)

- **`image1` = รูปหลัก** ใช้เป็นรูปในแบนเนอร์ข่าวเด่นหน้าแรก และรูปเล็กในหน้ารายการข่าว/ความรู้
- `image2` `image3` แสดงเฉพาะในหน้าเนื้อหาและในเส้นทางของเรา เว้นว่างได้
- ใส่กี่รูป เว็บจัดวางให้เอง รูปไม่ถูกตัด กดที่รูปเพื่อดูขนาดเต็ม
- แบนเนอร์หน้าแรกแสดงรูปเต็มทั้งรูป ไม่ตัดหัวตัดเท้า รูปแนวนอนจะดูเต็มแบนเนอร์ที่สุด

## ถ้าเว็บไม่เปลี่ยน
- รอ 2–5 นาที แล้วกด Ctrl + Shift + R
- ตรวจว่าชื่อแท็บและหัวคอลัมน์ถูกต้อง และชีตแชร์แบบ "ทุกคนที่มีลิงก์"
- ถ้าอ่านชีตไม่ได้ เว็บจะแสดงข้อมูลตัวอย่างเดิมแทน (เว็บจะไม่ล่ม)

⚠️ ชีตนี้ใครมีลิงก์ก็เปิดดูได้ **ห้ามใส่ข้อมูลลับ** เช่น ยอดขาย หรือเอกสาร GMP
